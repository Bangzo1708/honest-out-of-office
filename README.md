A brutally honest but still polite out-of-office auto-reply, in a single sentence of 190 characters: it admits what every employee only says privately — the inbox is a queue of 400 unread messages being politely pretended away — while still thanking the writer and promising a reply as soon as possible.

## Run it

```sh
python3 main.py
```
